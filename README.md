# Starter Brain

A brain for your business that AI reads every time you use it, so it answers like it knows your business. You never need to open these files. You talk to Claude and it looks after them.

## Set it up

1. Make a free account at [github.com](https://github.com).
2. At the top of this page, click **Use this template**, then **Create a new repository**. Give it a name, set it to **Private** and create it.
3. Download the [Claude desktop app](https://claude.ai/download) and sign in. You'll need a paid plan.
4. On Windows, install [Git for Windows](https://git-scm.com/download/win) first. On a Mac, click Install if it asks for developer tools.
5. In Claude, open the **Code** tab, connect your GitHub and choose the brain you just made.
6. Type `/setup` and answer the questions. Talking is easier than typing.

## Use it

- Ask it anything about your business, or give it a job: a reply, a quote follow-up, a price.
- When you tell it something new or correct it, say **"save that"**.
- Type `/setup` again any time to fill in what's still blank.

Never put passwords, bank or card numbers in here.
