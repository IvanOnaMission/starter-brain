# clients

One file per customer, named after them in lowercase-with-dashes: `john-smith.md`, `smith-builders.md`. It holds only what's true for that customer: contact person, sites, special pricing, preferences, notes from past jobs. Rules for every customer go in their topic folder instead.

Search this folder for the customer's name before creating a file, so they never end up with two.
